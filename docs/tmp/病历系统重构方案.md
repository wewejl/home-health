# 病历系统重构方案

## 1. 现状分析

### 1.1 现有系统

**后端已有模型：**
- `MedicalEvent` —— AI 对话生成的医疗事件
- `EventAttachment` —— 附件（基于 URL）
- `EventNote` —— 备注系统

**iOS 已有页面：**
- `MedicalDossierView` —— 病历夹列表页（搜索、筛选、事件卡片）
- `EventDetailView` —— 事件详情页（AI 摘要、分析、备注、时间轴）

### 1.2 存在的问题

1. 没有文件上传功能
2. 病历只能由 AI 对话自动生成，用户无法主动创建
3. 附件需要预上传的 URL，不支持直接上传
4. 缺少文件夹分类管理

## 3. 后端 API 设计

### 3.1 病历夹 API (`/medical-folders`)

| 方法 | 端点 | 描述 |
|------|------|------|
| POST | `/medical-folders` | 创建病历夹 |
| GET | `/medical-folders` | 获取用户的所有病历夹 |
| GET | `/medical-folders/{id}` | 获取病历夹详情 |
| PUT | `/medical-folders/{id}` | 更新病历夹 |
| DELETE | `/medical-folders/{id}` | 删除病历夹 |

**创建病历夹请求体：**
```json
{
  "name": "2024年体检",
  "description": "年度健康检查",
  "color": "#7B5FEA",
  "icon": "folder",
  "sort_order": 1
}
```

### 3.2 病历记录 API (`/medical-records`)

| 方法 | 端点 | 描述 |
|------|------|------|
| POST | `/medical-records` | 创建病历记录 |
| GET | `/medical-records` | 获取病历记录列表 |
| GET | `/medical-records/{id}` | 获取病历记录详情 |
| PUT | `/medical-records/{id}` | 更新病历记录 |
| DELETE | `/medical-records/{id}` | 删除病历记录 |
| GET | `/medical-records/by-folder/{folder_id}` | 获取指定文件夹下的记录 |

**创建病历记录请求体：**
```json
{
  "folder_id": "uuid",
  "title": "血常规检查",
  "record_date": "2024-01-15",
  "description": "年度体检血常规"
}
```

### 3.3 文件上传 API (`/medical-files`)

| 方法 | 端点 | 描述 |
|------|------|------|
| POST | `/medical-files/upload` | 上传文件（multipart/form-data） |
| GET | `/medical-files/{id}` | 获取文件信息 |
| PUT | `/medical-files/{id}` | 重命名文件 |
| DELETE | `/medical-files/{id}` | 删除文件 |
| GET | `/medical-files/record/{record_id}` | 获取记录的所有文件 |

**上传文件请求：**
```
POST /medical-files/upload
Content-Type: multipart/form-data

file: <文件二进制>
record_id: "uuid"
```

## 5. 文件存储方案

### 5.1 存储方式

| 方案 | 描述 | 推荐度 |
|------|------|--------|
| **本地存储** | 文件保存在 `backend/static/uploads/` | ⭐⭐⭐ MVP 方案 |
| **阿里云 OSS** | 对象存储，需要配置 | ⭐⭐⭐⭐ 生产环境 |
| **AWS S3** | 对象存储，国际通用 | ⭐⭐⭐⭐ 可选 |

### 5.2 本地存储结构

```
backend/static/uploads/
├── medical_files/
│   ├── {user_id}/
│   │   ├── {record_id}/
│   │   │   ├── original/
│   │   │   │   └── {file_id}.{ext}
│   │   │   └── thumbnails/
│   │   │       └── {file_id}_thumb.jpg
```

### 5.3 文件类型支持

| 类型 | 扩展名 | MIME Type |
|------|--------|-----------|
| 图片 | .jpg, .jpeg, .png, .heic | image/* |
| PDF | .pdf | application/pdf |
| 视频 | .mp4, .mov, .avi | video/* |
| 音频 | .mp3, .m4a, .wav | audio/* |
| 文档 | .doc, .docx, .txt | application/* |

### 5.4 缩略图生成

- **图片**：生成 200x200 JPEG 缩略图
- **PDF**：提取第一页作为缩略图
- **视频**：提取第一帧作为缩略图
- **音频**：使用默认音频图标
- **文档**：使用默认文档图标

## 6. 实施计划

### 6.1 开发优先级

**第一阶段：后端基础（必须）**
1. 创建数据模型（MedicalFolder, MedicalRecord, MedicalFile）
2. 实现文件上传 API
3. 实现基础 CRUD API
4. 数据库迁移脚本

**第二阶段：iOS 核心功能（必须）**
1. 修改 MedicalDossierView 添加文件夹展示
2. 新建 CreateRecordSheet 创建病历流程
3. 实现文件选择和上传
4. 文件网格展示

**第三阶段：完善功能（可选）**
1. 文件重命名、删除
2. 缩略图生成和展示
3. 文件预览（图片、PDF）
4. 文件夹管理（编辑、删除）

### 6.2 技术要点

**后端：**
- 使用 Python 快速开发框架 FastAPI
- 文件上传使用 `multipart/form-data`
- 缩略图使用 Pillow 生成
- 文件大小限制 50MB

**iOS：**
- 文件选择使用 `PHPickerViewController`（图片）和 `UIDocumentPickerViewController`（文件）
- 图片缓存使用 Kingfisher
- 网络请求复用现有 APIService
- 上传进度显示

### 6.3 数据库迁移 SQL

```sql
-- 新增病历夹表
CREATE TABLE medical_folders (
    id UUID PRIMARY KEY,
    user_id UUID NOT NULL REFERENCES users(id),
    name VARCHAR(255) NOT NULL,
    description TEXT,
    color VARCHAR(20),
    icon VARCHAR(50),
    sort_order INTEGER DEFAULT 0,
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW()
);

-- 新增病历记录表
CREATE TABLE medical_records (
    id UUID PRIMARY KEY,
    folder_id UUID NOT NULL REFERENCES medical_folders(id) ON DELETE CASCADE,
    user_id UUID NOT NULL REFERENCES users(id),
    title VARCHAR(255) NOT NULL,
    record_date DATE NOT NULL,
    description TEXT,
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW()
);

-- 新增文件表
CREATE TABLE medical_files (
    id UUID PRIMARY KEY,
    record_id UUID NOT NULL REFERENCES medical_records(id) ON DELETE CASCADE,
    user_id UUID NOT NULL REFERENCES users(id),
    filename VARCHAR(500) NOT NULL,
    file_type VARCHAR(50) NOT NULL,
    mime_type VARCHAR(100) NOT NULL,
    file_size BIGINT NOT NULL,
    url TEXT NOT NULL,
    thumbnail_url TEXT,
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW()
);

-- 索引
CREATE INDEX idx_medical_folders_user ON medical_folders(user_id);
CREATE INDEX idx_medical_records_user ON medical_records(user_id);
CREATE INDEX idx_medical_records_folder ON medical_records(folder_id);
CREATE INDEX idx_medical_files_user ON medical_files(user_id);
CREATE INDEX idx_medical_files_record ON medical_files(record_id);
```

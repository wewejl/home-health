# 架构设计

## 系统概述

### 项目简介

灵犀健康（Home Health）是一个医疗健康咨询应用，通过 AI 分身系统为用户提供智能医疗咨询服务。系统采用多智能体架构，支持不同科室的专科医生分身，能够进行图文对话、皮肤分析、报告解读等。

### 技术栈总览

| 模块 | 技术栈 | 说明 |
|------|--------|------|
| 后端 | Python + FastAPI + SQLAlchemy | RESTful API 服务 |
| 前端 | React + TypeScript + Vite + shadcn/ui (Radix) | 管理后台 |
| iOS | Swift + SwiftUI | 移动端应用 |
| 数据库 | PostgreSQL (业务) + SQLite (知识库) | 双数据库架构 |
| AI | 通义千问 (Qwen) + LangGraph + CrewAI | 多智能体框架 |

### API 设计原则

1. **RESTful 风格**：遵循 REST 规范设计 URL
2. **统一版本治理**：核心会话路由已统一为 `/sessions`
3. **统一响应格式**：使用 Pydantic 确保响应一致性
4. **错误处理**：统一的异常处理和错误响应

```yaml
# docker-compose.yml（简化示意）
services:
  postgres:
    image: postgres:16-alpine
    ports:
      - "5433:5432"
    environment:
      POSTGRES_DB: home_health
      POSTGRES_USER: postgres
      POSTGRES_PASSWORD: ${POSTGRES_PASSWORD}
    volumes:
      - postgres_data:/var/lib/postgresql/data

volumes:
  postgres_data:
```

### 环境配置

```env
# backend/.env 或 .env.local
DATABASE_URL=postgresql+psycopg://postgres:postgres@localhost:5433/home_health
KNOWLEDGE_DB_URL=sqlite:///./knowledge.db

# JWT 配置
JWT_SECRET_KEY=your-strong-jwt-secret
ADMIN_JWT_SECRET=your-strong-admin-jwt-secret

# LLM 配置
LLM_API_KEY=your-qwen-api-key

# 短信服务
SMS_ACCESS_KEY_ID=your-access-key
SMS_ACCESS_KEY_SECRET=your-access-secret
```

## 安全设计

### 认证机制

- 双认证方式：短信验证码 + 密码
- JWT Token：Access Token + Refresh Token
- 分离密钥：用户和管理员使用不同密钥

### 速率限制

```python
# 基于内存的滑动窗口算法
RATE_LIMIT_RULES = {
    "auth": {"max_requests": 5, "window": 60},      # 认证接口
    "upload": {"max_requests": 10, "window": 60},    # 上传接口
    "default": {"max_requests": 100, "window": 60},  # 默认
}
```

### CORS 配置

```python
CORS_ORIGINS = [
    "http://localhost:5173",  # 前端开发服务器
    "capacitor://localhost",  # iOS Capacitor
    # 生产环境域名
]
```

## 扩展性设计

### 智能体扩展

添加新科室智能体：

1. 在 `services/agents/` 创建新目录
2. 继承 `BaseAgentV2`
3. 实现科室特定的 Prompt 和工具
4. 在 `AgentRouterV2` 中注册

### API 版本管理

- 会话路由已统一为 `/sessions`
- 新接口默认不再新增 `v2` 后缀路由
- 历史文档中提到的 `/v2/sessions` 仅作迁移背景参考

### 数据库迁移

使用 Alembic 进行数据库版本管理：

```bash
# 生成迁移脚本
alembic revision --autogenerate -m "description"

# 执行迁移
alembic upgrade head
```

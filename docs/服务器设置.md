# 服务器设置

## 服务器信息

- **IP 地址**: 123.206.232.231
- **用户名**: ubuntu
- **密钥文件**: `.secrets/xinlingyisheng.pem`

## 连接服务器

```bash
# SSH 连接
ssh -i .secrets/xinlingyisheng.pem ubuntu@123.206.232.231
```

## 文件传输

```bash
# 上传文件到服务器
scp -i .secrets/xinlingyisheng.pem local_file.txt ubuntu@123.206.232.231:/path/to/destination/

# 从服务器下载文件
scp -i .secrets/xinlingyisheng.pem ubuntu@123.206.232.231:/path/to/file.txt ./
```

## 注意事项

- 密钥文件权限应设置为 600（已设置）
- `.secrets/` 目录已在 `.gitignore` 中，不会提交到 Git 仓库

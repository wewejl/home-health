## 一、后端 API 功能模块

### 1.1 用户认证模块 (`/auth`)

**路由文件**: `backend/app/routes/auth.py`

| 端点 | 方法 | 功能描述 |
|-------|------|----------|
| `/auth/send-code` | POST | 发送短信验证码 |
| `/auth/login` | POST | 手机号+验证码登录 |
| `/auth/login-password` | POST | 手机号+密码登录 |
| `/auth/register-password` | POST | 密码注册/设置密码 |
| `/auth/refresh` | POST | 刷新 Token |
| `/auth/check-phone` | GET | 检查手机号状态 |
| `/auth/me` | GET | 获取当前用户信息 |
| `/auth/profile` | PUT/POST | 更新/完善用户资料 |
| `/auth/password/set` | POST | 设置密码（已登录用户） |
| `/auth/password/reset` | POST | 重置密码 |

### 1.2 AI 问诊会话模块 (`/sessions`) - 核心功能

**路由文件**: `backend/app/routes/sessions.py`

| 端点 | 方法 | 功能描述 |
|-------|------|----------|
| `/sessions` | POST | 创建会话（支持多智能体类型） |
| `/sessions` | GET | 获取会话列表 |
| `/sessions/{id}/messages` | POST | 发送消息（支持流式SSE） |
| `/sessions/{id}/messages` | GET | 获取消息历史（支持分页） |
| `/sessions/agents` | GET | 获取所有可用智能体 |
| `/sessions/agents/{type}/capabilities` | GET | 获取智能体能力配置 |

**支持的智能体类型**:
- 全科 (general)
- 皮肤科 (dermatology)
- 心内科 (cardiology)
- 骨科 (orthopedics)
- 神经科 (neurology)
- 内分泌科 (endocrinology)
- 消化科 (gastroenterology)
- 呼吸科 (respiratory)

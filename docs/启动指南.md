# 启动指南

## 前置要求

**⚠️ 数据库使用 Docker 容器运行，启动前必须先启动 Docker**

## 项目概述

| 模块 | 技术栈 | 端口 | 说明 |
|------|--------|------|------|
| 数据库 | PostgreSQL (Docker) | 5433 | **必须先启动 Docker 容器** |
| 后端 | Python + FastAPI | 8100 | 依赖数据库 |
| 前端 | React + TypeScript + Vite | 5173 | 可选 |
| iOS | Swift + SwiftUI | - | 可选 |

---

## 1. 启动数据库（Docker 容器）

**第一步：必须先启动 PostgreSQL Docker 容器**

```bash
# 启动数据库容器
docker start home_health_db

# 验证容器运行
docker ps | grep home_health_db
```

---

## 2. 启动后端

```bash
cd backend
./venv/bin/python start_server.py
```

服务将在 http://localhost:8100 启动

### 验证后端

```bash
curl http://localhost:8100/
# 输出: {"message":"灵犀健康 AI分身系统 API 服务运行中","version":"2.0.0"}

# API 文档
open http://localhost:8100/docs
```

---

## 3. 启动前端（可选）

```bash
cd frontend
npm run dev
```

服务将在 http://localhost:5173 启动

---

## 4. 启动 iOS 应用（可选）

```bash
# 使用 Xcode 打开项目
open ios/xinlingyisheng/xinlingyisheng.xcodeproj
```

---

## 5. 常见问题

### PostgreSQL 连接失败

```bash
# 检查容器状态
docker ps | grep home_health_db

# 启动容器
docker start home_health_db

# 如需重建容器
docker-compose up -d postgres
```

### 端口被占用

```bash
# 查看端口占用
lsof -i :8100    # 后端
lsof -i :5173    # 前端

# 杀掉进程
lsof -ti :8100 | xargs kill -9
```

### 后端返回 SQLite 错误

检查 `backend/.env` 确保使用 PostgreSQL：

```env
DATABASE_URL=postgresql+psycopg://postgres:postgres@localhost:5433/home_health
```

---

## 6. 停止服务

```bash
# 停止后端
pkill -f "start_server.py"

# 停止前端
pkill -f "vite"

# 停止 PostgreSQL Docker 容器
docker stop home_health_db
```

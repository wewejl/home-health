# 灵犀健康 - 项目介绍

> 最后更新：2026-02-07

---

## 项目概述

**灵犀健康**是一款基于人工智能的医疗健康管理应用，帮助用户通过自然对话了解自身健康状况，智能整理病历数据，并监督医嘱执行情况。

---

## 三大核心功能

### 1️⃣ AI 智能问诊

用户通过对话与 AI 医生分身互动，系统智能收集健康信息：

| 功能 | 说明 |
|------|------|
| **多专科支持** | 13+ 专科医生分身（皮肤科、心内科、儿科、全科等） |
| **多模态输入** | 支持文字、语音（按住说话）、图片 |
| **智能分析** | AI 分析症状，评估风险等级（低/中/高/紧急） |
| **就医建议** | 给出是否需要线下就医的建议及紧急程度 |
| **自动记录** | 对话自动保存为医疗事件 |

**支持的科室**：皮肤科、心内科、全科、儿科、妇科、神经科、消化科、骨科等

---

### 2️⃣ 智能病历夹

自动整理和管理医疗记录，让病历一目了然：

| 功能 | 说明 |
|------|------|
| **医疗事件列表** | 按时间展示所有就诊记录 |
| **AI 摘要** | 自动生成就诊摘要（主诉、症状、诊断、建议） |
| **风险分级** | 每条记录标注风险等级 |
| **时间轴** | 完整的对话历史和附件记录 |
| **附件管理** | 支持图片、检查报告、音频、视频 |
| **搜索筛选** | 快速查找历史记录 |
| **PDF 导出** | 一键导出专业病历报告 |

**数据模型**：
- 会话记录（对话消息）
- AI 分析（诊断、建议、风险）
- 附件（图片/报告/音视频）
- 笔记（用户备注）

---

### 3️⃣ 医嘱监督与用药管理

帮助患者按时按量执行医嘱，提高治疗依从性：

| 功能 | 说明 |
|------|------|
| **医嘱类型** | 用药、监测、行为、复诊 |
| **任务提醒** | 按计划时间推送提醒 |
| **打卡完成** | 多种完成方式（打卡/拍照/记录数值） |
| **依从性统计** | 每日/每周完成率统计 |
| **异常警报** | 监测数值异常时自动告警 |
| **家属绑定** | 家属可接收通知，监督患者执行 |

**医嘱任务状态**：待完成、已完成、已超时、已跳过

## 技术架构

| 模块 | 技术栈 |
|------|--------|
| **用户端 (iOS)** | Swift + SwiftUI |
| **管理后台 (Web)** | React + TypeScript + Ant Design |
| **后端 API** | Python + FastAPI |
| **AI 引擎** | LangGraph + CrewAI |
| **语音识别** | FunASR / GLM-ASR |
| **数据库** | PostgreSQL |
| **知识库** | 医疗专业知识库 |

## 适用场景

| 场景 | 描述 |
|------|------|
| **日常健康咨询** | 身体不适时先问 AI，获取初步建议 |
| **慢病管理** | 高血压、糖尿病等需要长期监测和用药 |
| **儿童照护** | 家属监督儿童用药和健康行为 |
| **老人照护** | 家属远程了解老人健康状况 |
| **就诊整理** | 看病后自动整理病历，方便复诊 |

---

## 项目特色

- ✅ **13+ 专科医生分身** - 针对不同科室提供专业分析
- ✅ **多模态交互** - 文字、语音、图片均可
- ✅ **AI 自动整理** - 病历自动生成摘要和时间轴
- ✅ **医嘱执行监督** - 提醒、打卡、依从性统计
- ✅ **家属联动** - 家属可接收通知，共同关注健康
- ✅ **一键导出** - 生成专业 PDF 病历报告

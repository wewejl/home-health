## 一、组件使用规范

### 1.1 组件库选择

```
组件选择决策树
┌─────────────────────────────────────────────────────────┐
│                    需要组件？                            │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  ├── 图表？ ──→ @ant-design/charts                      │
│  │                                                      │
│  ├── 基础 UI (Button, Input, etc.)？ ──→ shadcn/ui      │
│  │                                                      │
│  ├── 复杂业务组件？ ──→ 基于 shadcn/ui 自定义           │
│  │                                                      │
│  └── 图标？ ──→ lucide-react                            │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 1.2 组件导入规范

```typescript
// ✅ 正确：使用 shadcn/ui 组件
import { Button } from '@/components/ui/button';
import { Card } from '@/components/ui/card';
import { Input } from '@/components/ui/input';
import { Table } from '@/components/ui/table';

// ✅ 正确：使用 lucide-react 图标
import { Search, User, Stethoscope } from 'lucide-react';

// ✅ 正确：使用医疗业务组件
import { StatCard, PageHeader, LoadingSkeleton } from '@/components/medical';

// ✅ 正确：使用 Ant Design 图表
import { Line } from '@ant-design/charts';

// ❌ 禁止：使用 Ant Design 基础组件
import { Button } from 'antd';  // 禁止！

// ❌ 禁止：使用 @ant-design/icons（图表页面除外）
import { SearchOutlined } from '@ant-design/icons';  // 禁止！
```

### 1.3 组件使用对照表

| 功能 | 禁止使用 | 应该使用 | 说明 |
|------|----------|----------|------|
| 按钮 | `antd.Button` | `@/components/ui/button` | shadcn/ui |
| 输入框 | `antd.Input` | `@/components/ui/input` | shadcn/ui |
| 卡片 | `antd.Card` | `@/components/ui/card` | shadcn/ui |
| 表格 | `antd.Table` | `@/components/ui/table` | shadcn/ui |
| 统计数字 | `antd.Statistic` | `@/components/medical/stat-card` | 自定义 |
| 加载状态 | `antd.Spin` | `@/components/medical/loading-skeleton` | 自定义 |
| 表单 | `antd.Form` | react-hook-form + zod | 后续实现 |
| 图表 | - | `@ant-design/charts` | 保留 |

## 二、样式规范

### 2.1 布局

```tsx
// ✅ 使用 Tailwind 类进行布局
<div className="flex items-center gap-4 p-6">
  <div className="flex-1">内容</div>
  <div>侧边</div>
</div>

// ❌ 不要使用内联样式
<div style={{ display: 'flex', padding: '24px' }}>
```

### 2.2 颜色

```tsx
// ✅ 使用语义化颜色变量
<div className="bg-primary text-primary-foreground">
<div className="text-success">
<div className="bg-warning-light/20">

// ❌ 不要使用硬编码颜色
<div className="bg-[#0EA5E9]">
<div style={{ color: '#10B981' }}>
```

### 2.3 圆角和边框

```tsx
// ✅ 使用 Tailwind 类
<div className="rounded-lg border border-border">

// ❌ 不要使用内联样式
<div style={{ borderRadius: '8px', border: '1px solid #e2e8f0' }}>
```

### 2.4 深色模式

```tsx
// ✅ 使用 dark: 前缀
<div className="bg-background dark:bg-surface text-foreground dark:text-foreground-secondary">

// ❌ 不要手动判断主题
<div className={isDark ? 'dark-bg' : 'light-bg'}>
```

    // ...
  }, []);

## 六、TypeScript 规范

### 6.1 类型定义

```tsx
// ✅ 为组件 Props 定义接口
interface ButtonProps {
  variant?: 'primary' | 'secondary';
  disabled?: boolean;
  onClick?: () => void;
}

// ✅ 为 API 响应定义类型
interface Patient {
  id: number;
  name: string;
  age?: number;
}

// ✅ 使用泛型
interface ApiResponse<T> {
  data: T;
  message?: string;
}

// ❌ 避免使用 any
const data: any = fetchData();  // 禁止！

// ✅ 使用 unknown 或具体类型
const data: unknown = fetchData();
```

### 6.2 类型导入

```tsx
// ✅ 推荐：使用 type 导入（减少编译产物）
import type { Patient } from '@/types';
import { useState } from 'react';

// ❌ 避免：混合导入
import { useState, type Patient } from './types';
```

## 七、性能优化

### 7.1 避免不必要的重渲染

```tsx
// ✅ 使用 useMemo 缓存计算结果
const filteredPatients = useMemo(
  () => patients.filter(p => p.name.includes(search)),
  [patients, search]
);

// ✅ 使用 useCallback 缓存函数
const handleClick = useCallback(() => {
  navigate(`/patients/${id}`);
}, [id, navigate]);

// ✅ 使用 React.memo 避免不必要的重渲染
const PatientCard = React.memo(({ patient }: Props) => {
  // ...
});
```

### 7.2 列表渲染

```tsx
// ✅ 使用稳定的 key
{patients.map(patient => (
  <PatientCard key={patient.id} patient={patient} />
))}

// ❌ 不要使用索引作为 key（除非列表是静态的）
{patients.map((patient, index) => (
  <PatientCard key={index} patient={patient} />
))}
```

## 八、代码审查检查点

### 提交 PR 前必须检查

- [ ] 没有使用 `antd` 的基础组件（Button, Input, Card, Table, Form）
- [ ] 没有使用 `@ant-design/icons`（图表页面除外）
- [ ] 颜色使用语义化变量（`bg-primary`, `text-success`）
- [ ] 深色模式正常工作
- [ ] 新组件放在正确的目录
- [ ] TypeScript 无类型错误
- [ ] ESLint 无警告
- [ ] 没有硬编码的颜色值
- [ ] 没有内联样式（除特殊需求外）
- [ ] 列表渲染使用稳定的 key

## 九、常见错误示例

### 错误 1：混用组件库

```tsx
// ❌ 错误
import { Button } from 'antd';
import { Card } from '@/components/ui/card';

// ✅ 正确
import { Button } from '@/components/ui/button';
import { Card } from '@/components/ui/card';
```

### 错误 2：硬编码颜色

```tsx
// ❌ 错误
<div style={{ color: '#0EA5E9' }}>

// ✅ 正确
<div className="text-primary">
```

### 错误 3：忽略深色模式

```tsx
// ❌ 错误
<div className="bg-white text-gray-900">

// ✅ 正确
<div className="bg-background text-foreground dark:bg-surface dark:text-foreground-secondary">
```

### 错误 4：内联样式

```tsx
// ❌ 错误
<div style={{ padding: '16px', borderRadius: '8px' }}>

// ✅ 正确
<div className="p-4 rounded-lg">
```

## 五、验收标准

### 必须通过 (P0)

- [ ] 所有 P0 API 返回正确数据

- [ ] 所有 P1 功能可用

### 可以延期 (P2)

## 六、Bug 严重级别

| 级别 | 定义 | 响应时间 |
|------|------|----------|
| 🔴 P0 - 阻塞性 | 系统崩溃、数据丢失、核心功能不可用 | 立即修复 |
| 🟡 P1 - 严重 | 主要功能异常、影响用户体验 | 24小时内 |
| 🟢 P2 - 一般 | 次要功能问题、UI 小瑕疵 | 下个迭代 |

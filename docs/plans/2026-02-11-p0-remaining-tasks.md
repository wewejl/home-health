## 任务 1: BE-P0-002 - 智能体框架重复实现

### 问题描述

后端 AI 服务同时支持 CrewAI 和 LangGraph 两套框架，导致：
- 代码冗余
- 维护困难
- 可能存在不一致行为

### 当前状态

**配置文件** (`backend/app/config.py:69`):
```python
USE_LANGGRAPH: bool = True  # 是否使用 LangGraph 替代 CrewAI
```

### 影响范围

需要检查的目录：
- `backend/app/services/ai/` - AI 服务层
- `backend/app/routes/` - 使用智能体的路由

### 执行方案

#### 阶段 1：代码审查
1. 列出所有 CrewAI 相关文件
2. 列出所有 LangGraph 相关文件
3. 确认 `USE_LANGGRAPH=True` 时，CrewAI 代码是否被调用
4. 确认是否有代码路径依赖 CrewAI

#### 阶段 2：决策
- 如果 LangGraph 完全替代 CrewAI：删除 CrewAI 代码
- 如果两者都使用：保留，但需要明确使用场景
- 如果迁移中：制定迁移计划

#### 阶段 3：执行（根据决策结果）
- 选项 A：删除 CrewAI 代码
- 选项 B：保留两者，添加文档说明
- 选项 C：分阶段迁移

### 验收标准

- [ ] 代码审查完成，明确使用状态
- [ ] 删除/保留决策已执行
- [ ] 相关测试通过
- [ ] 文档已更新

## 任务 2: IOS-P0-001 - iOS 对话页面输入框透明问题

### 问题描述

对话页面输入框透明导致显示异常。

### 初步检查结果

**文件**: `ios/xinlingyisheng/xinlingyisheng/Components/WeChatStyleInputBar.swift`

输入框已设置背景色：
```swift
HealingColors.warmCream  // Color(red: 0.97, green: 0.95, blue: 0.91)
```

### 需要验证

1. 在模拟器中运行，检查输入框显示
2. 检查是否有其他样式覆盖
3. 检查深色模式下的显示
4. 确认问题是否存在

### 执行方案

#### 阶段 1：问题确认
1. 在 Xcode 中构建并运行 iOS 项目
2. 导航到对话页面

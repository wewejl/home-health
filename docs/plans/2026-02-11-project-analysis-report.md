### P0 问题 (阻塞性)

1. **FE-P0-004: 皮肤科 AI 助手后端缺失**
   - 位置: `frontend/src/pages/DermaChat.tsx`
   - 问题: 前端调用 `/derma/start` 但后端没有实现
   - 影响: AI 助手功能完全无法使用
   - 建议: 实现后端端点或暂时隐藏功能

2. **FE-P0-005: /dashboard 路由缺失**
   - 位置: `frontend/src/App.tsx`
   - 问题: 导航链接存在但路由未定义
   - 影响: 点击后显示空页面
   - 建议: 实现 Dashboard 组件或移除导航链接

### P1 问题 (重要)

1. **BE-P1-001: API V1/V2 并存**
   - 影响: 维护成本高
   - 建议: 确认无调用方后删除 V1

### P2 问题 (优化)

1. **BE-P2-001: 测试覆盖不足**
   - 影响: 质量保障不足

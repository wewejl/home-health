### 2. iOS Keychain 降级

**文件**: `ios/.../Services/KeychainManager.swift`

**特性**:
- Keychain 失败时自动降级到 UserDefaults
- 记录降级日志用于监控
- 删除时同步清理两处存储

```swift
// 保存时自动降级
do {
    try saveToKeychain(value, forKey: key)
} catch {
    saveToUserDefaults(value, forKey: key)  // 降级
}
```

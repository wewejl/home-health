## 用户需求

> "平时看病后有一些病历资料，个人想整理上传到 App，下次医生可以直接看，去其他医院不需要带很多资料"

**核心场景**：
1. 用户拍照/上传医院的检查报告、处方单
2. 按医院/科室/日期整理分类
3. 就医时快速展示给医生看
4. 不需要携带纸质资料

### 数据模型

```swift
// 手动创建的病历（非AI生成）
struct ManualMedicalRecord {
    id: String
    hospitalName: String
    department: String
    visitDate: Date
    recordType: RecordType  // 检查/处方/其他
    chiefComplaint: String?
    attachments: [MedicalAttachment]
    notes: String?
    createdAt: Date
}

enum RecordType {
    case examination  // 检查
    case prescription   // 处方
    case discharge     // 出院小结
    case physical      // 体检
    case other         // 其他
}
```

## 交互流程

### 添加病历流程

```
病历列表页
    ↓
点击 [➕] 或 "添加我的病历"
    ↓
填写基本信息（医院、科室、日期）
    ↓
上传资料（拍照/相册/文件）
    ↓
保存 → 返回列表
```

### 就医展示流程

```
病历列表页
    ↓
点击 [展示模式⚡]
    ↓
进入就医展示模式
    ↓
向上滑动展示全部病历
    ↓
医生查看
    ↓
点击 [✕ 完成] 退出
```

## 设计原则

1. **简洁高效** - 最少步骤完成添加
2. **就医优先** - 展示模式一目了然
3. **离线可用** - 病历本地缓存
4. **快速分享** - 一键分享给医生

# 灵犀健康 - 前端管理后台

灵犀健康智能健康管理平台 - Web 管理后台

## 技术栈

- React 19
- TypeScript
- Vite
- Ant Design 5
- React Router

## 开发

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

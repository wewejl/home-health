## 工作规范

### 每次会话开始时
1. 阅读 README.md 了解项目全貌
2. 阅读 PROGRESS.md 了解当前进度
3. 阅读 claude-progress.txt 了解上次会话内容
4. 阅读 feature-list.json 了解功能状态
5. 运行 pwd 确认工作目录
6. 运行 git log --oneline -5 查看最近提交
7. 运行 init.sh 启动所有服务（如需要）

### 每次会话结束时
1. 更新 claude-progress.txt 记录本次会话工作
2. 更新 feature-list.json 状态（如有变化）
3. 更新 PROGRESS.md（官方进度文件）
4. 运行 git commit 提交代码（如有修改）
5. 记录下次会话需要继续的工作

## 技术栈

### 后端
- **语言**: Python 3.11+
- **框架**: FastAPI
- **数据库**: PostgreSQL (Docker)
- **ORM**: SQLAlchemy
- **启动**: docker-compose up -d backend

### 前端
- **语言**: TypeScript
- **框架**: React 18 + Vite
- **UI库**: shadcn/ui + Radix UI
- **启动**: cd frontend && npm run dev

### iOS
- **语言**: Swift 5.0+
- **框架**: SwiftUI
- **架构**: MVVM
- **启动**: 打开 Xcode 项目，选择模拟器运行

## 快捷命令

### Docker
```bash
# 启动所有服务
docker-compose up -d

# 启动后端
docker-compose up -d backend

# 查看日志
docker-compose logs -f backend

# 停止所有服务
docker-compose down
```

### 后端测试
```bash
# 运行所有测试
docker exec home_health-backend pytest

# 运行特定测试
docker exec home_health-backend pytest backend/tests/routes/test_sessions.py -v
```

### 前端
```bash
# 安装依赖
cd frontend && npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

### iOS 安全验证
```bash
# 运行安全检查脚本
bash scripts/ios/verify-security.sh
```

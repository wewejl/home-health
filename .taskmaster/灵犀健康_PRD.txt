<overview>
## Problem Statement

传统医疗健康咨询存在以下痛点：
1. **就医不便**：患者需要亲自前往医院
2. **医疗资源不均**：优质医疗资源集中在大城市
3. **咨询成本高**：时间和经济成本高
4. **健康数据分散**：病历分散在各个机构
5. **医嘱执行缺乏监督**：医生难以了解医嘱执行情况

## Target Users

| 用户角色 | 核心需求 |
|----------|----------|
| **普通患者** | 快速医疗咨询，图文/语音咨询 |
| **慢性病患者** | 医嘱提醒、用药监督 |
| **患者家属** | 远程查房、医嘱监督 |
| **医生** | 患者管理、医嘱开具 |

## Success Metrics

| 指标 | 目标 | 状态 |
|------|------|------|
| 用户认证成功率 | > 95% | ✅ |
| AI 响应时间 | < 3 秒 | ✅ |
| 语音识别准确率 | > 90% | ✅ |

</overview>

- **Description**: 手机号+密码登录

- **Outputs**: Access Token、Refresh Token

- **Description**: 刷新 Access Token

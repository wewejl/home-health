# 灵犀健康

灵犀健康智能健康管理平台

## 项目简介

灵犀健康是一款智能健康管理平台，提供 AI 医生分身、远程查房、患者依从性管理等医疗健康服务。

## 项目结构

```

├── backend/       # Python FastAPI 后端服务

```

## 技术栈

| 模块 | 技术栈 |
|------|--------|
| 后端 | Python + FastAPI + SQLAlchemy |
| 前端 | React + TypeScript + Vite |
| iOS | Swift + SwiftUI |
